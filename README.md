# 🎯 Hobby Tracker App

A simple web application to track your hobbies, interests, and learning progress.

## Features

- ✅ Add new hobbies with category (Programming, Quantum Computing, ML, etc.)
- ✅ Track difficulty level from 1-10
- ✅ Persistent storage using localStorage
- ✅ Clean modern UI with gradient design
- ✅ Responsive layout for mobile devices
- ✅ Easy delete functionality

## Tech Stack

| Technology | Purpose |
| :--- | :--- |
| HTML5 | Structure and markup |
| CSS3 | Styling with gradients and animations |
| Vanilla JavaScript (ES6+) | App logic, no frameworks needed |
| localStorage | Data persistence without a backend |

## How to Use

1. **Open `index.html`** in your browser (double-click or drag into Chrome/Firefox/Edge)
2. Fill out the form on the top section:
   - Enter hobby name (e.g., "Python", "Photography")
   - Select category from dropdown
   - Set difficulty level 1-10
3. Click **"Add Hobby"** to save it!
4. View your hobbies list below and delete any you want.

## Customization Ideas

- 🎨 Change colors in `styles.css` to match your theme
- ➕ Add new categories to the dropdown list
- 💾 Export hobbies as JSON by modifying app.js
- 🔗 Integrate with GitHub for version tracking
